# services/catalogue

Exercise names, muscle groups, equipment, instructions. Seeded from Free Exercise DB; ExerciseDB and wger are candidate additional sources. Every data source must be approved by the owner and recorded in `docs/SOURCES.md` before import.

- **Status.** Scaffold only. Implementation lands in Stage 2.
- **Proposed language.** TypeScript (pending owner approval).
- **Infra.** Cloudflare Worker.
- **Data store.** Cloudflare D1.
- **Events in.** None.
- **Events out.** None.

See `docs/architecture.md` for context.
