# apps/web

React + TypeScript PWA shell. Installable to the home screen, offline-capable.

- **Status.** Scaffold only. Implementation lands in Stage 2.
- **Proposed language.** TypeScript (pending owner approval).
- **Hosting.** Vercel free tier.
- **Depends on.** All backend services via API Gateway or Cloudflare Workers, authenticated with the Cognito JWT.
- **Events in.** None.
- **Events out.** None (emits HTTP calls).

See `docs/architecture.md` for context.
